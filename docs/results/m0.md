# M0 results - measured 2026-11-13

Raw numbers: [m0.json](m0.json). Table samples: [m0-tables/](m0-tables/). Script: `scripts/m0_measure.py`.

## Corpus

11 PDFs, 24 MB, all verified against `corpus/manifest.json`. **892 pages, 5.16 million characters.**
Each PDF's own cover says which year it is for, and it matches the plan: Publication 17 for 2023,
2024 and 2025; every other publication for 2025.

## Decisions

| Question | Measured | Decision |
| --- | --- | --- |
| Prose extractor | Publication 17, 142 pages: PyMuPDF 0.5 s, pdfplumber 61.1 s; both had 0 run-together words (22+ letter tokens) and 0 replacement characters across all 11 PDFs | **PyMuPDF** for prose |
| Table extractor | Standard Deduction chart (p17 page 97, p501 page 25): pdfplumber clean (`Single or Married filing separately` / `$15,750`), PyMuPDF's table finder glues words (`Singleor...`, `$15750 ,`) | **pdfplumber** for tables, only on pages that have them |
| Giant lookup tables | The Tax Table (p17, 3 editions) and the Earned Income Credit table (p596 pages 30-39) defeat both extractors: one keeps columns but garbles text, the other packs dozens of rows into one cell | **Out of scope for v0.1**: no passages, no eval questions; stated as a limitation. A dedicated parser is a stretch goal |
| Passage size | ~180 words: 5,613 passages; **~300 words: 3,253**; ~450 words: 2,119. All fit free Vectorize (limit ~13,000 at 384 dims) | **~300 words** (about 400 tokens, under bge-small's 512) |
| Oversized blocks | 70 single paragraphs over 380 words, max 1,559: tables of contents (dot leaders), the EIC table, lookup pages | skip contents and index pages; drop the lookup tables (above); split anything still over 380 words at sentences |
| Embeddings, local vs cloud | 100 passages: local fastembed `bge-small-en-v1.5` vs Workers AI, **pooling `cls`: mean cosine 1.0000, min 1.0000**; pooling `mean` (Workers AI default): mean 0.9014, min 0.8551 | build the index locally for free; query through Workers AI **with `pooling: "cls"`** |
| Quotes | 6,141 curly quotes in the corpus | the citation check normalizes quotes and whitespace on both sides before comparing |
| Table detection cost | PyMuPDF `find_tables` on every page took most of the 931 s M0 run | never run table detection on every page in the pipeline |
